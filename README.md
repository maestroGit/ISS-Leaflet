# 🌍 ISS-Leaflet

Un rastreador en tiempo real de la Estación Espacial Internacional (ISS) usando la API de geolocalización y Leaflet.js para la visualización global sobre un mapa interactivo.

## 🚀 Demo

Accede a la aplicación en vivo:  
[https://iss-leaflet.vercel.app/](https://iss-leaflet.vercel.app/)

## 📝 Descripción

**ISS-Leaflet** permite visualizar la posición actual de la ISS sobre la Tierra en tiempo real. Utiliza la API pública [Where the ISS at?](https://wheretheiss.at/w/developer) para obtener las coordenadas actualizadas y Leaflet.js para mostrar la ubicación en un mapa interactivo.

## 🧰 Tecnologías

- **JavaScript Vanilla**
- **Leaflet.js**
- **API REST "Where the ISS at?"**
- **HTML5 & CSS3**

## ⚙️ Instalación y uso

1. Clona este repositorio:
    ```bash
    git clone https://github.com/maestroGit/ISS-Leaflet.git
    cd ISS-Leaflet
    ```

2. Abre el archivo `index.html` en tu navegador favorito.

No se requieren dependencias adicionales. Todo funciona directamente en el navegador.

## ✨ Funcionalidades

- Muestra la ubicación en tiempo real de la ISS sobre un mapa mundial.
- Actualización automática de la posición cada pocos segundos.
- Interfaz sencilla y visualmente atractiva.
- 100% frontend, sin backend necesario.
